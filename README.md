#  hao_rover仿真机器人系统

##  项目概述
本项目是一个基于 **ROS2 (Robot Operating System 2)** 构建的机器人仿真系统。
该项目将集成多传感器与模型，赋予仿真机器人更强的环境理解能力、语义分析能力与智能决策水平。
该项目会分成多个版本，我会在每个版本中不断添加新的功能

##  核心特性
- **ROS2 架构驱动**：利用 ROS2 的分布式通信机制（DDS），确保系统的高实时性、低延迟与模块化扩展能力。
- **多传感器融合**：集成激光雷达（LiDAR）、深度相机（RGB-D）、惯性测量单元（IMU）等多种传感器，模拟真实物理环境下的复杂数据输入。
- **模型赋能**：自行采集数据训练模型，让机器人有更强的识别能力
- **高仿真**：在仿真环境中快速验证算法逻辑，大幅降低实机调试成本与风险。
